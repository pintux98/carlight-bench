        Phone music sync

        The phone listens through its microphone: louder music makes the lights brighter while the colour slowly drifts, like the original app's Music tab. For the controller's own microphone, use the Music options above.

        Custom colour sequence

        Handle and foot lights. Uses brightness, speed and zones from Manual control.

        Find separate lights

        Flashes red using a different hidden code each time. After each flash, tap what turned red. Test 1 is a check where everything in that group should go red.

        Uses only the "set colour" command. Nothing is saved on the controller; switching the lights off and on again undoes everything.

        Results

        Cop patterns

        The phone switches lights between red and blue. Side A starts red, side B starts blue. Lights found under Find separate lights appear in these lists. Patterns also work as looks.

        Settings

        Milliseconds between commands. Lower makes cop patterns snappier; raise it if the lights miss commands. The original app used 100.

        Safety lock: only display commands can be sent (power, colour, brightness, speed, effects, scenes, music, clock). Factory reset, wiring order, LED counts and pairing commands are blocked in code.
